# 🧮 Calculadora Simples

Uma **calculadora simples e funcional** desenvolvida com **HTML, CSS e JavaScript**, focada em praticar manipulação do DOM, eventos e lógica em JavaScript puro (sem frameworks).

---

## ✨ Funcionalidades

✅ Operações básicas

* ➕ Adição
* ➖ Subtração
* ✖️ Multiplicação
* ➗ Divisão

✅ Outros recursos

* 🔢 Uso de parênteses `( )`
* 🧹 Botão **C** para limpar tudo
* ⬅️ Botão para apagar um dígito
* 🟰 Botão de resultado
* ⌨️ Suporte à tecla **Enter** para calcular
* 🔒 Display somente leitura (evita digitação manual)

---

## 🛠️ Tecnologias Utilizadas

* 🌐 **HTML5** — estrutura da calculadora
* 🎨 **CSS3** — estilização e layout
* ⚙️ **JavaScript (ES6+)** — lógica, eventos e cálculos

---

## 🧠 Conceitos Praticados

* Factory Function
* Manipulação do DOM
* Delegação de eventos
* Uso de `this` e arrow functions
* Tratamento de erros com `try/catch`
* Conversão de operadores (`x → *`, `÷ → /`)
* Uso do `eval()` de forma controlada, apesar de não ser o ideal!
